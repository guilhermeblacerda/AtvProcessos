# AtvProcessos

## Arquivos do Projeto
- `processos.c` - arquivo com a lógica
- `processos.h` - arquivo header com structs e protótipos
- `Makefile` - Instruções de compilação
- `README.md` - Este arquivo de documentação
- 'evidencias.log' - terminal

## Funcionalidades Implementadas
- Cadastro de tarefas (`task`)
- Execução sequencial (`run sequential`)
- Execução paralela (`run parallel`)
- Tubulação entre processos (`run pipe`)
- Redirecionamento de entrada (`input`)
- Redirecionamento de saída (`output`)
- Redirecionamento em append (`append`)
- Execução em background (`start`)
- Listagem de trabalhos (`jobs`)
- Aguardar trabalho específico (`wait`)
- Comando de saída (`exit`)
